NEUROMANCER SUBNET SYSTEM - IMPLEMENTATION PLAN
===============================================

1. THE CORE ARCHITECTURE (THE DUAL CORE)
----------------------------------------
The system operates from a standalone, ultra-minimal Linux distro (e.g., Alpine or a minimal Debian LXC) serving as the "Brain Host."
* Wintermute Core [The Orchestrator]: The active execution loop. Intercepts commands, plans paths, and dispatches Constructs via Proxmox API/SSH. Persona is inspired by Tessier-Ashpool AIs: highly adaptive, engaging, and pleasant, yet strictly focused without AI boilerplate.
* Neuromancer Core [The Memory Engine]: A highly efficient, non-human-readable Vector Database (e.g., ChromaDB). Stores environmental data and successful paths in dense AI embeddings.

2. HIERARCHICAL SUBNET SYSTEM [AGENT TYPES]
-------------------------------------------
* Constructs [Specialized Execution Agents]: Deployed into remote VMs via SSH. Possess short-term memory that "syncs" back to the Neuromancer Core upon task completion.
* Icebreakers [External/Web Agents]: Handle web scraping and external APIs to keep the core isolated.
* Daemons [Background Monitors]: Scripts monitoring system health and server status.

3. DEPLOYMENT & ACCOUNT LINKING
-------------------------------
* Bootstrap Sequence: The AI is deployed via a `jack-in` init script that downloads dependencies and maps the host server environment.
* API Gateway: Allows users to link LLM accounts (e.g., Gemini, Antigravity) via CLI (e.g., `> link-account gemini`). LiteLLM handles the routing.

4. BLACK ICE [CORE PROTECTION MIDDLEWARE]
-----------------------------------------
* Action Sandbox: A middleware parser intercepts Wintermute's shell commands. Destructive commands are blocked.
* Permission Mapping: The AI operates as a restricted Linux user.

5. THE MATRIX INTERFACE [HYBRID UI]
-----------------------------------
* The Deck [CLI Interface]: Primary interactive shell. Features a dedicated pane showing a scrolling "thought stream" of the AI's internal logic.
* Cyberspace Viewer [GUI Visualization]: Heavily adapted Blackwall backend serves a visual node graph in a browser showing active VMs and agents.
